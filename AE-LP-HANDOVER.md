### 5a. What was done (18 Sep 2026)

**Lead pipeline (task 1).** New n8n workflow **"01Wire AE — Lead Capture"** (`4Frt564hkcEPaeD9`, active) on path `/webhook/01wire-ae-lead`. It mirrors the India workflow with three deliberate differences:

- Phone gate is `^\+9715[0-9]{8}$` instead of the Indian mobile pattern.
- It writes to its **own** n8n data table **"01Wire AE Leads"** (`F4az0GffOpRKJvDL`) and its own **"AE Leads"** tab in the existing `pr-reseller data sheet`, so AE leads never mix with India leads and the AE-only `timeline` / `client_count` fields have somewhere to land. Nothing in the India pipeline was touched.
- The Google Chat alert nodes **are connected**. In the India workflow they are orphaned, so the "🔥 NEW LEAD" card has never fired for anything; AE gets new-lead and repeat-lead cards in the same Chat space. If AE should alert somewhere else, say so.

Honeypot, 5-second time gate, disposable-email block and phone+funnel dedupe all carry over. The sheet node writes with `cellFormat: RAW` so the leading `+` survives (the India sheet loses it).

**Tracking (tasks 3–4)** verified in the browser, not assumed: `gtm.js?id=GTM-WFLR2PF` loads, GA4 `g/collect` fires, the pixel fires `ev=PageView`, and on submit the page pushes `lead_form_submit_attempt` → `generate_lead` → `fbq('track','Lead',{content_name:'pr-reseller-ae'})` → `lead_thank_you` on `/ae/thank-you/`.

**Mobile QA (task 7)** found two real defects in `SocialProofAe.tsx`, both fixed:

- The screenshot cards said "TAP TO VIEW COVERAGE" but only had `group-hover:` styles, so on touch there was nothing to tap. The `<figcaption>` is now focusable (`tabIndex={0}` + `aria-label`) with matching `group-focus:` variants, so a tap reveals the article and a second tap elsewhere hides it. Keyboard users get it too.
- `blur-0` **does not exist in Tailwind v4** — it compiles to nothing, so the revealed screenshot stayed blurred even on hover. Replaced with `blur-[0px]`.

No horizontal overflow at 375px; the comparison table scrolls inside its own `overflow-x-auto` wrapper.

**India parity check.** `/`, `/thank-you/` and `/free-listing-sites/` were built from the merge-base commit (`9b16af0`) and from this branch and compared. After normalising per-build chunk filenames, the only remaining difference is the Next.js build id, which changes on every build. Compiled CSS is a superset: moving `@theme inline` → `@theme` makes India utilities resolve through `var(--color-*)` instead of literal hex (same computed value), and it drops the wide-gamut `lab()` companion declarations on translucent brand colours — imperceptible in sRGB, very slightly different on P3 displays.
